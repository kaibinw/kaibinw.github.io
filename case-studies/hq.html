A browser control panel that turns headless agentic automations into one-click buttons.

SLATE PROBLEM BUILD PROOF NEXT

Problem

The vault's automations only run from a terminal, and the people who share the house won't open one. They needed a browser button that runs one job and shows the output.

Constraints set before building

Zero dependenciesOne Node file, no node_modules, nothing to install or update. Any Node ≥18 runs it.
The vault is the databaseNo copy of the data anywhere. The panel renders the markdown files directly and writes checkbox ticks straight back to them.
Local onlyBinds to 127.0.0.1. The page is not served on the network.
Nothing destructive one click awayButtons only run additive automations; the vault's hard rules (never delete, always log) hold underneath.

What I built

Each button sends a stored prompt to a headless agent in the vault. Output streams into the panel, and the run is logged. The button list is a JSON file.

What it shows

  • The agent is a subprocess, so a browser button can run it.
  • One Node file and no packages, so nothing drifts out of date.
  • Buttons only run additive work, and every run is logged.
